# StatSkill AI 🇮🇳
### *Empowering India's Statistical Workforce with AI-Driven Skill Intelligence*

**StatSkill AI** is an enterprise, government-grade skill intelligence and adaptive capacity building platform engineered for India's Official Statistical System (**MoSPI, NSO, State Directorates of Economics & Statistics, and Training Academies like NSSTA**).

---

## 🌟 The Central Intelligence Loop

StatSkill AI is built on the closed-loop workforce intelligence paradigm:
$$\text{PROFILE} \longrightarrow \text{ASSESS} \longrightarrow \text{IDENTIFY GAP} \longrightarrow \text{RECOMMEND} \longrightarrow \text{LEARN} \longrightarrow \text{RE-ASSESS} \longrightarrow \text{UPDATE COMPETENCY}$$

> **Core Value Proposition:** *“Don't search for what to learn. Let AI identify what you need to learn next.”*

---

## 🚀 Key Modules & Capabilities

1. **Official Landing Page & Dual-Role Authentication**:
   - Government-grade theme adhering to GIGW accessibility, national emblem styling, and bilingual Indian accents.
   - 1-Click Demo Logins for **Official** (*Rajesh Sharma - Statistical Officer, MoSPI*) and **Administrator** (*Dr. Sunita Rao - Director Training, NSSTA*).
2. **Official Competency Profile & Onboarding**:
   - 4-Tier Competency Matrix: **Statistical Competencies** (Survey Design, Sampling, SNA 2008, CPI/WPI, NQAF), **Technical Competencies** (Python, SQL, R, AI/ML, GIS, Cloud), **Digital Governance** (DPDP 2023, Cybersecurity, DPI), and **Behavioural/Managerial**.
3. **Official Dashboard**:
   - **72% Overall Competency Progress Ring**, interactive competency bars, Top Identified Skill Gaps (High/Medium severity), and AI course recommendations.
4. **Adaptive AI Competency Assessment**:
   - Item-level difficulty adaptation (scales Easy $\to$ Medium $\to$ Hard based on real-time responses) with official explanations and instantaneous dynamic profile scoring.
5. **AI Skill-Gap Analysis**:
   - Compares verified scores against national cadre benchmarks with visual radar overlays, bar deficits, and strategic AI summaries.
6. **4-Phase Personalized Learning Roadmap**:
   - **Phase 1 (Foundation)** $\to$ **Phase 2 (Applied Skills)** $\to$ **Phase 3 (Advanced)** $\to$ **Phase 4 (Domain Application)**.
7. **iGOT Karmayogi Course Integration**:
   - 6-Factor AI Recommendation Engine ($35\%$ Skill Gap + $25\%$ Job Role + $15\%$ Prior Learning + $10\%$ Career + $10\%$ Dept + $5\%$ Emerging Tech) with *"Why this course?"* rationale and direct enrollment.
8. **NSSTA TPAC Residential Training Programmes**:
   - Curated residential, online, and hybrid capacity development masterclasses at NSSTA Greater Noida campus.
9. **AI Assessment & Quiz Generator (Trainer / Director ⭐)**:
   - Upload PDF, PPT, DOC, or TXT materials; AI extracts statistical domain knowledge to synthesize customizable examination questions with distractor explanations and publishes them to official cadres.
10. **StatBot 🤖 Floating AI Virtual Assistant**:
    - Context-aware conversational statistical intelligence assistant available throughout the platform.
11. **Executive Workforce Analytics & Future Prediction ⭐**:
    - 12,450 officials breakdown across departments, 5-year predictive AI horizon scanning (2026-2030), and pre- vs. post-training ROI uplift tracking (+29% to +33% competency improvement).

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Recharts, Canvas Confetti
- **Backend**: Node.js, Express, TypeScript, Multer, REST APIs
- **Persistence**: High-performance typed database engine with realistic Indian statistical cadre seed data
- **AI Abstraction**: Pluggable AI Service supporting Gemini/OpenAI API or local deterministic domain-expert statistical engine

## ⚡ Quick Start

### 1. Start the Backend Server (Port 5000)
```powershell
cd server
npm install
npm run build
npm start
```

### 2. Start the Frontend Client (Port 5173)
```powershell
cd client
npm install
npm run dev
```

Visit `http://localhost:5173` in your browser.
